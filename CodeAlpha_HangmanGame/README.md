# Hangman Game

A text-based Hangman game where the player guesses a hidden word one letter at a time.

> Built as part of the **CodeAlpha Python Programming Internship**.

## Features
- Random word chosen from a list of 5 predefined words
- Maximum of 6 incorrect guesses
- Input validation (single letters only, no repeated guesses)
- Option to play again

## Technologies Used
- Python 3 (random module, loops, strings, lists)

## How to Run
1. Install [Python 3](https://www.python.org/downloads/).
2. Clone this repository:
   ```bash
   git clone https://github.com/YOUR_USERNAME/CodeAlpha_HangmanGame.git
   cd CodeAlpha_HangmanGame
   ```
3. Run the program:
   ```bash
   python hangman.py
   ```
