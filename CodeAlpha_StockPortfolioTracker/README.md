# Stock Portfolio Tracker

A console app that calculates the total value of your stock investments using predefined stock prices.

> Built as part of the **CodeAlpha Python Programming Internship**.

## Features
- Hardcoded dictionary of stock prices (AAPL, TSLA, GOOGL, MSFT, AMZN)
- Enter stock symbols and quantities interactively
- Displays per-stock value and total investment
- Optionally saves the summary to `portfolio_summary.txt`

## Technologies Used
- Python 3 (dictionaries, file handling, input validation)

## How to Run
1. Install [Python 3](https://www.python.org/downloads/).
2. Clone this repository:
   ```bash
   git clone https://github.com/YOUR_USERNAME/CodeAlpha_StockPortfolioTracker.git
   cd CodeAlpha_StockPortfolioTracker
   ```
3. Run the program:
   ```bash
   python stock_tracker.py
   ```
