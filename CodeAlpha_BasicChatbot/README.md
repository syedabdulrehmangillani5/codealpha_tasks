# Basic Chatbot

A simple rule-based chatbot that replies to predefined user messages.

> Built as part of the **CodeAlpha Python Programming Internship**.

## Features
- Responds to greetings, "how are you", "what is your name" and "help"
- Friendly fallback reply for unknown messages
- Type `bye` to exit

## Technologies Used
- Python 3 (functions, if-elif, loops)

## How to Run
1. Install [Python 3](https://www.python.org/downloads/).
2. Clone this repository:
   ```bash
   git clone https://github.com/YOUR_USERNAME/CodeAlpha_BasicChatbot.git
   cd CodeAlpha_BasicChatbot
   ```
3. Run the program:
   ```bash
   python chatbot.py
   ```

## Sample Output
```

You: hello
Bot: Hi!
You: how are you
Bot: I'm fine, thanks!
You: bye
Bot: Goodbye!
```
